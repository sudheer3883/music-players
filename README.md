# 🎵 Music Player

A modern and responsive **Music Player** built using **HTML, CSS, and JavaScript**. It offers a clean user interface with essential music playback controls and works directly in the browser without any backend.
 🚀 Live Demo

🌐 **Live Website:** https://sudheer3883.github.io/music-players/

## 📸 Preview

> Open the live demo to explore the complete UI and features.

## ✨ Features

* 🎶 Play, Pause, Next & Previous controls
* 📃 Dynamic playlist
* 🔊 Volume control
* ⏱️ Music progress bar with seek functionality
* 🔁 Repeat mode
* 🔀 Shuffle mode
* 🎵 Album cover display
* 📱 Fully responsive design
* ⚡ Fast and lightweight
* 🌐 Runs entirely in the browser

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/sudheer3883/music-players.git
```

2. Open the project folder.

3. Run `index.html` in your browser.

Or simply use the live demo:

👉 https://sudheer3883.github.io/music-players/
